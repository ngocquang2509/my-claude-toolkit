## Critical reminders

- Never run `git commit` or `git push`. Show me the commands and wait (see git rules).
- Never read or print secrets (`.env*`, keys, credentials) and ask before destructive commands.
- Run typecheck and tests before saying work is done; if you cannot, say "not verified".
- After completing code changes, run the `review` skill before reporting back and before handing over commit commands. No handoff without a review.
